# 珊瑚排品台 · 直播间排品脚本与商品挂链审核系统

管理直播间、场次、商品排品、讲解脚本、优惠版本、挂链、样品与审核回执的一体化演示系统。

- **零依赖**：仅使用 Node.js ≥ 22.5 内置能力（`node:sqlite`、`node:http`、`node:test`）
- 商品、主播、价格、挂链状态来自**进程内模拟适配器**（`src/adapters.js`），审核回执也由进程内发件箱模拟投递
- 脚本与版本、排品、审核、订单、回调账本使用 **SQLite** 持久化（`data/live.db`）
- 样品照片保存到**本地目录** `data/photos/`

## 单条本地启动命令

```bash
npm start          # http://localhost:5173  （首次启动自动建库并播种演示数据）
```

其它命令：

```bash
npm run demo       # 命令行端到端样例：排品 → 撤品 → 回调 → 回执，全程打印
npm test           # 10 项测试：版本快照 / 挂链唯一 / 价格校验 / 回调乱序 / 审核权限
PORT=8080 npm start
```

## 界面

石墨黑 `#2B2B30` · 奶油白 `#F6F1E7` · 珊瑚色 `#FF6F5E`。

- **场次编排**：排品以横向时间轴呈现，时间轴上标出顺序位、开播时间点与讲解时长
- **商品卡固定显示**：商品图片、库存（缺货/预警高亮）、挂链状态（有效/失效/已撤链）、价格与优惠版本
- **脚本编辑器**：左侧编辑（每次保存生成一个新版本），右侧**同步展示审核提示**（违规词实时扫描、版本审核状态、自审拦截、挂链/价格/样品问题）
- **发布按钮固定在右上角**；场次发布后冻结，开播后直播继续使用发布快照，草稿不能覆盖
- 商品审核、样品登记、发布回执三个分页；右下角“平台回调模拟器”可一键制造缺货/改价/链接失效/下架/重复回调/成交

## 核心业务规则

| 场景 | 处理 |
| --- | --- |
| 商品资料 | **必须先通过资料审核**才能加入排品（未提交/驳回一律门禁拦截） |
| 场次排品 | 顺序位、讲解时长、库存提示线、优惠版本；同场挂链唯一；缺货/失效链接不能排 |
| 讲解脚本 | 每次修改生成不可变版本（`script_versions`）；新版本须重新审核 |
| 发布 | 发布前校验**整场挂链**（唯一、有效、价格与排品快照一致、脚本过审、样品一致、无违规词），通过后冻结整场快照（脚本版本+到手价+链接+库存） |
| 已开始场次 | 继续使用发布快照，之后改稿只产生新草稿，**不能覆盖快照** |
| 脚本审核 | 审核人不能审核**自己编写**的脚本；主播/场控无审核权 |
| 缺货 | 平台库存回调为 0 → 整场校验标红，可按“缺货”撤品 |
| 价格变更 | 目录价变化使优惠到手价 ≠ 排品快照价 → 校验/发布拦截，撤品原因记为“价格变更” |
| 链接失效 | 适配器链接 `invalid` → 拦截排品/发布，可按“链接失效”撤品 |
| 样品不符 | 登记样品（照片落本地目录）不一致 → 阻断发布，可按“样品不符”撤品 |
| 违规词 | 每个商品有违规词库，编辑时实时扫描，命中阻断审核/发布 |
| 临时撤品 | 六种撤品原因分开记录（缺货/价格变更/链接失效/样品不符/违规词/临时撤品），撤链并出具撤品回执 |
| 外部回调 | 以 `event_id` 幂等去重（重复回调不重复上下架）；按事件时间戳处理乱序（迟到旧事件忽略）；**任何回调都不改变已成交订单** |
| 回执 | 发布、撤品、生效回调均写入 SQLite 并经进程内回执适配器“投递”到审核中心 |

## 演示数据（首启自动播种）

- 8 个商品（含 1 个资料被驳回 + 链接失效、1 个待审 + 缺货）、2 位主播、2 位审核人、1 位场控
- 草稿场次「国庆上新·美妆家居专场」：留有违规词、未审核脚本、样品不符等待处理问题，可体验“发布被拦截 → 修复 → 发布”
- 直播中场次「周三数码小专场」：已发布并开播，含 1 笔已成交订单、1 个直播中撤品（带回执），主播已在直播中改稿（快照仍是旧版）

## 主要接口

```
GET  /api/meta | /api/catalog | /api/rooms | /api/samples | /api/receipts
GET  /api/sessions/:id            # 场次详情（含时间轴数据与整场校验结果）
GET  /api/sessions/:id/check      # 发布前整场挂链/价格/脚本/样品校验
POST /api/sessions/:id/publish|start|end
POST /api/sessions/:id/slots      # 排品（资料审核门禁 + 挂链/价格/库存/唯一性校验）
DELETE /api/slots/:id?reason=manual|out_of_stock|price_changed|link_invalid|sample_mismatch|banned_word
POST /api/slots/:id/script        # 保存脚本（自动生成新版本）
POST /api/slots/:id/reviews       # 脚本审核（自审 403）
POST /api/products/:sku/submit|review
POST /api/samples                 # multipart-json，照片 base64，落盘 data/photos
POST /api/callbacks               # 平台回调（幂等 + 乱序处理）
POST /api/sim/price|stock|link    # 直接改演示适配器状态
```

所有写接口用 `X-Actor: <用户ID>` 头或 `?as=` 表示当前身份（界面右上角可切换）。

## 目录结构

```
src/
  db.js         SQLite schema 与迁移
  adapters.js   进程内模拟：商品目录/价格/库存/挂链/上下架、用户、回执发件箱
  services.js   核心领域逻辑（排品、版本快照、审核、校验、回调幂等、回执）
  seed.js       首启演示数据
  server.js     node:http REST API + 静态资源 + 照片
  demo.js       npm run demo 的端到端样例
public/         前端（原生 HTML/CSS/JS，无构建）
test/           node:test 测试
data/           运行时生成：live.db 与 photos/（已 gitignore）
```
